## 前端 UI 设计要求

本项目为教育场景下的 AI 编程助教。

参考面试公司现有 AI 助教产品的视觉风格。

## 视觉参考

参考截图：`docs/ui-reference.png`

该截图用于参考现有产品的配色、  
布局、视觉层级与交互风格。

不要求像素级复刻，应结合 AI 编程助教  
的实际业务需求进行适配。

### 视觉风格

- 使用浅紫色 + 白色作为主要配色。
- 采用柔和、低饱和度的教育 AI 产品风格。
- 主区域以白色为主，侧栏使用极浅紫色。
- 卡片以细边框、圆角、轻阴影为主。
- 保持充足留白，避免复杂的 IDE 式界面。
- 使用简洁的中文字体、Lucide 图标。
- 优先复用 shadcn/ui 组件。

### 交互布局

1. 左侧：历史会话、备课任务、工作区入口。
2. 中间：AI 对话、执行过程、输入框。
3. 右侧：可展开的备课产物工作区。
4. 首页使用简洁的居中欢迎页。
5. 用户发起任务后，切换至任务执行布局。

### 教育场景

- 输入区支持学段、年级、课程主题等教学上下文。
- 支持上传班级练习数据。
- 教案、示例代码、分层练习应有独立的查看区域。
- 验证结果需要清晰可辨。
- 接受、拒绝、回退等教师操作必须明显。

### 产品差异

参考现有产品的视觉语言，但不能只做聊天界面。

必须突出以下编程 Agent 能力：

- 工作区文件树
- 文件 Diff
- 真实代码执行结果
- 测试用例与失败信息
- Agent 工具执行过程
- 教师审核及版本回退

### 开发约束

- 不改变既定 Python + FastAPI + React 技术栈。
- 不因 UI 优化修改无关后端逻辑。
- 不增加复杂的完整 IDE 功能。
- 先保证面试题 P0 完成，再做视觉细节优化。
- 不直接复制公司 Logo、产品名称及品牌素材。
